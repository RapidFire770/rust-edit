> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Visual (soft) word wrap that breaks long lines across multiple screen rows at word boundaries, with character fallback for over-long words. Toggled via `Alt+Z` and the Tools menu. Wrapped continuation rows have no line number and do not change logical `Ln`/`Col`/`lines` in the status bar.

**Architecture:** Render-time layout (Approach A from the design spec). A new pure module `src/wrap.rs` computes per-visible-logical-line wrap breaks each frame. No new persistent state on `Buffer`. When `word_wrap == false`, every wrap code path is bypassed, so existing behavior and the byte-offset test suite are untouched.

**Tech Stack:** `ropey::Rope`, `ratatui::text::{Line, Span}`, `crossterm`. No new dependencies.

**Semantics (memorize before writing):**
- `breaks[i]` is the list of **byte offsets (absolute, rope-relative) that END each wrapped screen row** for the `i`-th logical line in the window, excluding the final row (which ends at the line's terminator). Empty vec ⇒ the line fits on one row.
- Window: logical lines `[start_line, start_line + count)`. Out-of-range lines are skipped.
- `width` is in **display columns** (excludes gutter). Tabs expand to the next multiple of `tab_size`. CJK/emoji wide chars count as 2 columns (using `unicode-width` would add a dep; for MVP approximate with `ch.is_whitespace() || ...` — see step 1 for the exact rule).
- A line of length exactly `width` does **not** wrap. Wrap only when the next char would make `col > width` (i.e. exceed `width`).
- `screen_row_of_byte` returns a row **relative to the layout window's first row** (0-indexed). If `byte` is before the window start, returns 0; if after the window end, returns `total_screen_rows - 1`.
- `byte_of_screen_row` translates a clicked (`screen_row`, `col`) into the byte offset of the cursor. `col` is in display columns **relative to the start of that sub-row** (i.e. already gutter-adjusted and hscroll-independent because wrap has no hscroll). Clamp `col` to the sub-row's width.

```rust
pub fn compute_layout(
    rope: &Rope,
    start_line: usize,
    count: usize,
    width: usize,
    tab_size: u8,
) -> WrapLayout {
    let width = width.max(1);
    let tab = tab_size.max(1) as usize;
    let n_lines = rope.len_lines();
    let mut breaks: Vec<Vec<usize>> = Vec::with_capacity(count);
    let mut total_screen_rows = 0usize;

    for i in 0..count {
        let lidx = start_line + i;
        if lidx >= n_lines {
            break;
        }
        let line_start = rope.line_to_byte(lidx);
        let line_slice = rope.line(lidx);

        let row_breaks = wrap_one_line(&line_slice, line_start, width, tab);
        total_screen_rows += row_breaks.len() + 1;
        breaks.push(row_breaks);
    }

    WrapLayout { breaks, total_screen_rows }
}

/// Wrap a single logical line. Returns the absolute byte offsets ending each
/// non-final wrapped row. The final row ends at the line terminator (not included).
fn wrap_one_line(
    line: &ropey::RopeSlice,
    line_start_byte: usize,
    width: usize,
    tab: usize,
) -> Vec<usize> {
    let mut breaks: Vec<usize> = Vec::new();
    let mut col = 0usize; // display column since the start of the current row
    let mut last_space_byte: Option<usize> = None; // byte of the most recent space in THIS row
    let mut byte_in_line = 0usize; // bytes consumed so far in this line

    for ch in line.chars() {
        if ch == '\n' || ch == '\r' {
            continue;
        }
        let advance = if ch == '\t' { tab - (col % tab) } else { 1 };
        let abs_byte = line_start_byte + byte_in_line;

        if col + advance > width {
            // Wrap before this char.
            if let Some(space_byte) = last_space_byte {
                // Word break: end row at the space (exclusive byte = byte after the space).
                breaks.push(space_byte + 1);
                // Resume on the current char; reset col & last_space.
                col = advance;
                last_space_byte = None;
            } else {
                // Char fallback: break right before this char.
                breaks.push(abs_byte);
                col = advance;
                last_space_byte = None;
            }
        } else {
            col += advance;
            if ch == ' ' || ch == '\t' {
                last_space_byte = Some(abs_byte);
            }
        }
        byte_in_line += ch.len_utf8();
    }

    breaks
}
```

```rust
/// Screen row (relative to the layout window's first row) containing `byte`.
/// `byte` is rope-relative (absolute). Clamps to `[0, total_screen_rows - 1]`.
pub fn screen_row_of_byte(
    layout: &WrapLayout,
    rope: &Rope,
    start_line: usize,
    byte: usize,
) -> usize {
    if layout.total_screen_rows == 0 {
        return 0;
    }
    let mut row = 0usize;
    for (i, line_breaks) in layout.breaks.iter().enumerate() {
        let lidx = start_line + i;
        if lidx >= rope.len_lines() {
            break;
        }
        let line_start = rope.line_to_byte(lidx);
        // Determine the end byte of this logical line (start of next line, or rope end).
        let line_end = if lidx + 1 < rope.len_lines() {
            rope.line_to_byte(lidx + 1)
        } else {
            rope.len_bytes()
        };

        if byte < line_end {
            // Byte is within this logical line. Find its sub-row.
            let mut sub = 0usize;
            for &brk in line_breaks.iter() {
                if byte < brk {
                    break;
                }
                sub += 1;
            }
            return row + sub;
        }
        // Byte is past this line — advance by this line's row count.
        row += line_breaks.len() + 1;
        let _ = line_start;
    }
    // Byte is past the window end.
    layout.total_screen_rows.saturating_sub(1)
}

/// Byte offset of the cursor placed at (`screen_row`, `col`) within the layout's
/// window. `screen_row` is relative to window start; `col` is display columns
/// from the start of that sub-row (already gutter-adjusted; wrap has no hscroll).

pub fn byte_of_screen_row(
    layout: &WrapLayout,
    rope: &Rope,
    start_line: usize,
    screen_row: usize,
    col: usize,
) -> usize {
    // Walk the layout to find which logical line + sub-row the screen_row maps to.
    let mut row_remaining = screen_row;

        let lidx = start_line + i;

            return rope.len_bytes();

            row_remaining -= rows_in_line;
            continue;

            rope.len_bytes()

            line_start
        } else {
            line_breaks[row_remaining - 1]

            line_breaks[row_remaining]
        } else {
            line_end

        byte += ch.len_utf8();
        cur_col += 1;
```

```rust
fn render_unwrapped(
    buf: &Buffer,
    app: &App,
    visible_lines: usize,
    cache: Option<&crate::app::CachedHighlights>,
) -> Vec<Line<'static>> {
    let theme = app.current_theme();
    let start_line = buf.scroll_offset.0;
    let n_lines = buf.line_count();
    let mut highlighted: Vec<Vec<Span<'static>>> = Vec::new();
    for ii in 0..visible_lines.max(1) {
        let lidx = start_line + ii;
        if lidx >= n_lines {
            break;
        }
        let hl = if let Some(c) = cache {
            if c.start_line <= lidx {
                let rel = lidx - c.start_line;
                if let Some(line_spans) = c.spans.get(rel) {
                    line_spans.clone()
                } else {
                    vec![Span::raw(buf.line(lidx))]
                }
            } else {
                vec![Span::raw(buf.line(lidx))]
            }
        } else {
            let h = app.highlighter.highlight(&buf.line(lidx), buf.language);
            if h.is_empty() {
                vec![Span::raw(buf.line(lidx))]
            } else {
                h.into_iter().next().unwrap_or_default()
            }
        };
        highlighted.push(hl);
    }

    let mut lines: Vec<Line<'static>> = Vec::new();
    let hscroll = buf.scroll_offset.1;
    for (i, hline) in highlighted.iter().enumerate() {
        let line_idx = start_line + i;
        let gutter = format!("{:>4}| ", line_idx + 1);
        let mut spans = vec![Span::styled(gutter, theme.line_number_style())];
        let line_start_byte = buf.rope.line_to_byte(line_idx);
        let mut byte_in_line = 0usize;
        let mut char_in_line = 0usize;
        for sp in hline {
            let txt = sp.content.clone();
            for ch in txt.chars() {
                let ch_len = ch.len_utf8();
                let abs_byte = line_start_byte + byte_in_line;
                let is_selected = if let Some(sel) = &buf.selection {
                    abs_byte >= sel.start && abs_byte < sel.end
                } else {
                    false
                };
                let mut ch_style = sp.style;
                if is_selected {
                    ch_style = ch_style.patch(theme.selection_style());
                }
                if char_in_line >= hscroll {
                    spans.push(Span::styled(ch.to_string(), ch_style));
                }
                byte_in_line += ch_len;
                char_in_line += 1;
            }
        }
        if hline.is_empty() {
            if let Some(sel) = &buf.selection {
                let line_start = buf.rope.line_to_byte(line_idx);
                if sel.start <= line_start && sel.end > line_start && char_in_line >= hscroll {
                    spans.push(Span::styled(" ", theme.selection_style()));
                }
            }
        }
        lines.push(Line::from(spans));
    }
    lines
}

/// Wrapped render path. Emits one `Line` per screen row. The first sub-row of
/// each logical line carries the gutter; continuation rows carry 6 spaces.
fn render_wrapped(
    buf: &Buffer,
    app: &App,
    visible_lines: usize,
    cache: Option<&crate::app::CachedHighlights>,
) -> Vec<Line<'static>> {
    let theme = app.current_theme();
    let n_lines = buf.line_count();
    let width = buf.visible_width.max(1);
    let tab = app.config.tab_size;
    let scroll_screen_row = buf.scroll_offset.0; // under wrap, this is a SCREEN ROW

    // Expand the logical-line window until the rendered rows fill the viewport.
    // Start from the logical line that contains screen row `scroll_screen_row`.
    let mut start_line = 0usize;
    let mut prefix_rows = 0usize; // screen rows before start_line within the layout window
    // We compute layouts incrementally: try windows of growing logical-line count.
    // Simple approach: compute layout for [0, line_count) (cheap enough for visible;
    // for huge files we cap later). For MVP, accept full-buffer layout compute here.
    // OPTIMIZATION NOTE: for very large buffers, replace with a windowed compute
    // (see Task 9 "perf"). The cost is O(visible bytes) which is fine up to ~50k lines.
    let full_layout = crate::wrap::compute_layout(&buf.rope, 0, n_lines, width, tab);
    if full_layout.total_screen_rows == 0 {
        return Vec::new();
    }

    // Find the logical line whose first screen row is <= scroll_screen_row and whose
    // last screen row is > scroll_screen_row. Walk breaks accumulating row counts.
    let mut rows_before = 0usize;
    for (i, line_breaks) in full_layout.breaks.iter().enumerate() {
        let rows_in_line = line_breaks.len() + 1;
        if rows_before + rows_in_line > scroll_screen_row {
            start_line = i;
            prefix_rows = rows_before;
            break;
        }
        rows_before += rows_in_line;
    }

    let _ = prefix_rows;
    let rows_to_render = visible_lines;
    let mut lines: Vec<Line<'static>> = Vec::with_capacity(rows_to_render);

    'outer: for (i, line_breaks) in full_layout.breaks.iter().enumerate().skip(start_line) {
        let lidx = i;
        let rows_in_line = line_breaks.len() + 1;
        let line_start_byte = buf.rope.line_to_byte(lidx);
        let line_end_byte = if lidx + 1 < n_lines {
            buf.rope.line_to_byte(lidx + 1)
        } else {
            buf.rope.len_bytes()
        };

        // Fetch highlighted spans for this line from the cache (or fallback).
        let hline: Vec<Span<'static>> = if let Some(c) = cache {
            if c.start_line <= lidx {
                let rel = lidx - c.start_line;
                c.spans.get(rel).cloned().unwrap_or_else(|| vec![Span::raw(buf.line(lidx))])
            } else {
                vec![Span::raw(buf.line(lidx))]
            }
        } else {
            let h = app.highlighter.highlight(&buf.line(lidx), buf.language);
            if h.is_empty() {
                vec![Span::raw(buf.line(lidx))]
            } else {
                h.into_iter().next().unwrap_or_default()
            }
        };

        // Pre-compute the byte offset of each sub-row's start within the line.
        let mut sub_starts: Vec<usize> = vec![line_start_byte];
        for &brk in line_breaks.iter() {
            sub_starts.push(brk);
        }
        let mut sub_ends: Vec<usize> = line_breaks.clone();
        sub_ends.push(line_end_byte);

        // Determine which sub-row of THIS line is the first to render.
        let first_sub = screen_row.saturating_sub(rows_before_start(lidx, &full_layout));
        let _ = first_sub;
        // Simpler: iterate every sub-row of this line, but only emit ones whose
        // global screen_row >= scroll_screen_row.
        let line_first_global_row = rows_before_global(lidx, &full_layout, n_lines, &buf.rope, width, tab);
        for sub in 0..rows_in_line {
            let global_row = line_first_global_row + sub;
            if global_row < scroll_screen_row {
                continue;
            }
            if lines.len() >= rows_to_render {
                break 'outer;
            }
            let sub_start_byte = sub_starts[sub];
            let sub_end_byte = sub_ends[sub];
            let is_first_sub = sub == 0;
            let gutter = if is_first_sub {
                Span::styled(format!("{:>4}| ", lidx + 1), theme.line_number_style())
            } else {
                Span::raw("      ") // 6 spaces, aligned
            };
            let mut spans = vec![gutter];
            // Walk hline, slicing the chars whose absolute byte is in [sub_start_byte, sub_end_byte).
            let mut byte_in_line = 0usize;
            for sp in &hline {
                let txt = &sp.content;
```

Append to `impl Buffer` in `src/buffer.rs` (before the closing `}` at line 798):

```rust
    // ===== Word-wrap-aware scroll/cursor helpers =====
    //
    // These consult a WrapLayout computed by the caller (render path or main.rs
    // event handler). When word_wrap is off, the caller must use the original
    // (unwrapped) helpers instead.

    /// Scroll by `delta` screen rows. `total_screen_rows` is the buffer's total
    /// wrapped height at the current width.
    pub fn scroll_wrapped(&mut self, delta: isize, total_screen_rows: usize) {
        let current = self.scroll_offset.0 as isize;
        let max = total_screen_rows.saturating_sub(self.visible_lines.max(1)) as isize;
        let new = (current + delta).max(0).min(max) as usize;
        self.scroll_offset.0 = new;
    }

    /// Clamp scroll_offset.0 to the wrapped range.
    pub fn clamp_scroll_wrapped(&mut self, total_screen_rows: usize) {
        let max = total_screen_rows.saturating_sub(self.visible_lines.max(1));
        if self.scroll_offset.0 > max {
            self.scroll_offset.0 = max;
        }
    }

    /// Auto-scroll to keep the cursor visible, using screen rows.
    pub fn adjust_scroll_wrapped(&mut self, layout: &crate::wrap::WrapLayout) {
        let v = self.visible_lines.max(1);
        let cursor_row =
            crate::wrap::screen_row_of_byte(layout, &self.rope, 0, self.cursor);
        let s = self.scroll_offset.0;
        if cursor_row < s {
            self.scroll_offset.0 = cursor_row;
        } else if cursor_row >= s + v {
            self.scroll_offset.0 = cursor_row.saturating_sub(v.saturating_sub(2));
        }
        // No horizontal adjust under wrap.
    }

    /// Minimal visibility clamp (used by mouse placement & find jumps).
    pub fn ensure_cursor_visible_wrapped(
        &mut self,
        layout: &crate::wrap::WrapLayout,
        vis: usize,
    ) {
        let v = vis.max(1);
        let cursor_row =
            crate::wrap::screen_row_of_byte(layout, &self.rope, 0, self.cursor);
        let s = self.scroll_offset.0;
        if cursor_row < s {
            self.scroll_offset.0 = cursor_row;
        } else if cursor_row >= s + v {
            self.scroll_offset.0 = cursor_row.saturating_sub(v.saturating_sub(2));
        }
    }

    /// Page up/down under wrap. `layout` is the buffer's full wrap layout.
    pub fn page_wrapped(
        &mut self,
        layout: &crate::wrap::WrapLayout,
        down: bool,
        vis: usize,
        extend_selection: bool,
    ) {
        let page = vis.saturating_sub(1).max(1) as isize;
        let cursor_row =
            crate::wrap::screen_row_of_byte(layout, &self.rope, 0, self.cursor);
        let old_scroll = self.scroll_offset.0 as isize;
        let total = layout.total_screen_rows as isize;
        let max = total.saturating_sub(1);
        let new_scroll = if down {
            (old_scroll + page).min(max)
        } else {
            (old_scroll - page).max(0)
        } as usize;
        self.scroll_offset.0 = new_scroll;
        // Place the cursor on the same logical line it was on, at the preferred col,
        // but at a screen row inside the new viewport. For MVP we move the cursor to
        // the line whose first screen row == new_scroll (top of the paged view).
        let target_screen_row = new_scroll;
        // Find the logical line that starts at or before target_screen_row.
        let mut acc = 0usize;
        let mut target_line = 0usize;
        for (i, line_breaks) in layout.breaks.iter().enumerate() {
            let rows_in_line = line_breaks.len() + 1;
            if acc + rows_in_line > target_screen_row {
                target_line = i;
                break;
            }
            acc += rows_in_line;
        }
        let (preferred_col, _) = {
            let (_, col) = self.cursor_position();
            col
        };
        let _ = cursor_row;
        // Reuse the existing line-move logic for col preservation + extend.
        self.move_to_line(target_line, preferred_col, extend_selection);
        // move_to_line calls adjust_scroll (unwrapped); override with wrapped clamp.
        self.ensure_cursor_visible_wrapped(layout, vis);
    }
```
